## How to Run

### Prerequisites

Make sure Java is installed on your system.

Check your Java installation using:

```bash
java --version
```

### Clone the Repository

```bash
git clone https://github.com/Sumaira-K/DSA.git
cd DSA
```

### Compile and Run a Program

Navigate to the required directory and compile the Java file:

```bash
javac HalfPyramid.java
```

Then run it using:

```bash
java HalfPyramid
```

Replace the filename and class name with the program you want to execute.
